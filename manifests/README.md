# Frozen qid manifests

- `popqa_dev1000_qids.txt`: 1,000 examples used during development.
- `popqa_test13267_qids.txt`: development-disjoint PopQA evaluation subset.
- `entityquestions_test5000_qids.txt`: frozen non-overlapping EntityQuestions test.

The complete PopQA collection is the union of its two manifests. These files
contain identifiers only; obtain questions and aliases from the official
benchmark releases.
